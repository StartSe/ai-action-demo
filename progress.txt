## Codebase Patterns
- **(US-014, `simulador-vendas`) Semeadura idempotente de dados modelo em SQLite:** quando um app precisa de um pequeno conjunto fixo de registros prontos na primeira execução (ex.: 3 cenários de cliente simulado), usar **ids fixos e conhecidos** (não `crypto.randomBytes(...)`) para esses registros específicos e `INSERT OR IGNORE INTO tabela (id, ...) VALUES (?, ...)` chamado no início de toda função de leitura/escrita da tabela (com uma flag `semeado` em memória para não repetir a query a toda chamada dentro do mesmo processo). Isso garante que rodar a semeadura várias vezes, em processos diferentes, ou mesmo depois de o usuário apagar manualmente um dos registros modelo, nunca duplica nada — ao contrário de um `if (count === 0) semear()`, que resemearia tudo se o usuário tivesse apagado só um dos três. Registros criados pelo próprio usuário continuam usando o gerador de id aleatório normal; só o conjunto modelo fixo usa id determinístico.
- **(US-014) Uma nota geral (ou qualquer agregado numérico) devolvida por uma análise via IA nunca deve ser confiada como veio do modelo, mesmo se o prompt pedir explicitamente**: calcular sempre no servidor a partir dos valores individuais que a IA devolveu (ex.: `nota` geral = média aritmética das notas por critério, arredondada com `Math.round(x*10)/10`), e só formatar com `numero(n, 1)` (`lib/formato.ts`, vírgula pt-BR) na hora de exibir — o valor armazenado continua `number`. Mesmo princípio já registrado para `ondeDiscordam` em `bussola-ia` e para fontes/citações em `radar-sinais`/`voz-do-cliente`: qualquer agregação ou seleção que o servidor já tem todos os dados para calcular sozinho não deve ser delegada à IA, mesmo que seja mais simples pedir no prompt.
- Gráficos SVG com `viewBox` escalado (`width:100%`) fazem o texto interno (`<text>`/classe `text-[Npx]`) escalar junto com a largura do container — o mesmo tamanho fica ilegível no celular e gigante no desktop. Solução usada em `financas-ia` (US-044, `GraficoMeses`/`GraficoCategorias`): abandonar `<svg>` e desenhar em HTML puro. Para "colunas" lado a lado com texto (rótulo embaixo de cada barra, valor sobre a barra), usar **CSS Grid com `grid-template-columns: repeat(N, minmax(0, 1fr))`**, nunca Flexbox `flex-1`: com `flex: 1 1 0%`, se mais de uma coluna tiver texto não-vazio, o `flex-shrink` não encolhe de forma confiável abaixo do `min-content` mesmo com `min-w-0`+`truncate` em todas elas, e a fileira toda estoura a largura do cartão (comprovado medindo `scrollWidth`/`getBoundingClientRect` via Playwright). `minmax(0,1fr)` no Grid nunca deixa a grade ficar mais larga que o container. Relevante para qualquer gráfico de barras futuro da suíte (ex. US-045 em `voz-do-cliente`).
