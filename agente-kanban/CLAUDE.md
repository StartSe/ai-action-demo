## Notas específicas deste app

- `lib/historico.ts`/`lib/sensivel.ts`/`lib/formato.ts`/`instrumentation.ts`/`components/setup.tsx`/`lib/setup-comum.ts` são cópias literais de `pdi-time` (arquivos genéricos, sem lógica específica do app). Só `app/r/[id]/page.tsx`, `app/imprimir/[id]/page.tsx` e os `not-found.tsx` são próprios daqui, porque dependem do `Resultado`/tipo de dado deste app. A integração própria (Trello) mora só em `lib/integracoes.ts`.
- Este app não tem um "resultado" único como o PDI (um formulário que gera um plano). O "resultado" salvo no histórico é cada chamada ao agente (`POST /api/agente`): `entrada = { mensagem }`, `saida = ResultadoAgente` (resposta, ações, quadro, alterados). `GET /api/quadro` (carga inicial da página) devolve `meta` mas não salva no histórico — só ações do agente viram um link permanente.
- `Empty` é usado de verdade aqui (diferente de `Destaque`/`Dropzone` em `pdi-time`, que ficam só exportados): quando o quadro carregado tem zero cartões em todas as listas, `Stage` mostra `Empty` com a ilustração "quadro de três colunas" e o botão "Testar com um exemplo" chama `enviarMensagem(EXEMPLO_COMPOSTO)` diretamente.
- **Bug de corrida corrigido aqui, relevante para as próximas réplicas (US-018 a US-025):** o efeito que carrega o estado inicial (`carregarQuadro`/equivalente) e o efeito do atalho `?exemplo=1` disparam os dois com `setTimeout(..., 0)` no mesmo mount. Se ambos chamam a mesma API (ou uma API e a outra escrevem no mesmo estado), o que responder por último vence e pode sobrescrever `meta`/`id`/resposta do outro com dados mais "pobres" (sem citar a ação que acabou de rodar). Correção: o efeito de carga inicial verifica `?exemplo=1` e não dispara quando o atalho já vai carregar o estado sozinho via `enviarMensagem`/`gerar`.
- Também corrigido em `pdi-time/components/ui.tsx` (fonte compartilhada, então já replicado aqui): `Entregar` calculava `link` com `location.origin` direto no corpo da função, o que quebra com `ReferenceError: location is not defined` em `/r/[id]` e `/imprimir/[id]` (Server Components que renderizam esse Client Component no servidor). Corrigido com `typeof window !== "undefined" ? ... : undefined`. Ao replicar `ui.tsx` para os próximos apps, usar a versão já corrigida (não a versão antiga que só existia em capturas de tela anteriores a esta história).
